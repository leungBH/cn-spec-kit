# 验收标准文档

> 本模板定义 ToB 系统验收标准的标准结构。每个功能必须有正常流程、异常场景、边界条件的验收标准。

---

## 1. 功能验收标准

### AC-{{编号}}: {{功能名称}}

#### 正常流程验收

| 验收项 | 操作步骤 | 预期结果 |
|--------|----------|----------|
| {{如：创建合同}} | 1. 进入合同列表页 → 2. 点击新建 → 3. 填写表单 → 4. 点击保存 | 合同创建成功，状态为草稿，列表中可见新合同 |
| {{如：提交审批}} | 1. 选择草稿合同 → 2. 点击提交审批 → 3. 选择审批人 | 合同状态变为待审批，审批人收到通知 |
| {{如：审批通过}} | 1. 审批人登录 → 2. 打开审批列表 → 3. 点击通过 | 合同状态变为已通过，提交人收到通知 |
| {{如：查看列表}} | 1. 进入合同列表 → 2. 使用筛选 → 3. 查看表格 | 列表按筛选条件显示，可排序、分页 |

#### 异常场景验收

| 异常场景 | 操作步骤 | 预期结果 |
|----------|----------|----------|
| {{如：网络中断提交}} | 填写表单 → 断网 → 点击保存 | 显示"保存失败，请重试"，数据不丢失 |
| {{如：并发编辑}} | 两人同时编辑同一合同 | 后提交者收到"数据已被修改"提示 |
| {{如：审批退回}} | 审批人点击退回 → 填写退回原因 | 合同状态变为已退回，提交人收到退回通知和原因 |
| {{如：重复提交}} | 草稿状态点击提交 → 再次点击提交 | 第二次点击提示"合同已在审批中" |
| {{如：删除保护}} | 非草稿状态点击删除 | 提示"只有草稿状态可删除" |

#### 边界条件验收

| 边界条件 | 测试场景 | 预期结果 |
|----------|----------|----------|
| {{如：空数据}} | 合同列表无数据 | 显示空状态插图和引导文案 |
| {{如：大数据量}} | 列表显示10000+条数据 | 分页正常，查询不超时 |
| {{如：特殊字符}} | 合同名称输入特殊字符<>&"' | 正常保存，显示时不被解析为HTML |
| {{如：超长文本}} | 备注500字上限 | 超出时提示字数限制 |
| {{如：金额边界}} | 合同金额输入0或负数 | 提示"金额必须大于0" |
| {{如：日期边界}} | 到期日期早于生效日期 | 提示"到期日期不能早于生效日期" |

#### 权限验收

| 权限场景 | 操作步骤 | 预期结果 |
|----------|----------|----------|
| {{如：角色可见性}} | 普通员工登录 → 查看合同列表 | 只能看到本人创建的合同 |
| {{如：跨部门限制}} | 部门A员工查看部门B合同 | 看不到部门B的合同（无穿透权限） |
| {{如：操作权限}} | 普通员工点击删除按钮 | 按钮不显示或提示"无操作权限" |
| {{如：审批权限}} | 非审批人尝试审批 | 审批操作按钮不显示 |

## 2. 非功能验收标准

### 2.1 性能验收

| 验收项 | 测试条件 | 验收标准 |
|--------|----------|----------|
| 页面首屏加载 | 正常网络、普通数据量 | < 2秒 |
| 列表查询 | 1万条数据、常用筛选 | < 3秒 |
| 报表生成 | 月度报表导出 | < 10秒 |
| 并发操作 | 50人同时操作 | 无明显延迟 |

### 2.2 安全验收

| 验收项 | 测试条件 | 验收标准 |
|--------|----------|----------|
| 登录安全 | 弱密码尝试 | 拒绝弱密码 |
| 数据隔离 | 跨分公司查询 | 无法查看其他分公司数据 |
| XSS防护 | 输入脚本代码 | 不被执行 |
| 操作审计 | 关键操作记录 | 审计日志完整 |

### 2.3 兼容性验收

| 验收项 | 测试条件 | 验收标准 |
|--------|----------|----------|
| 浏览器兼容 | Chrome/Edge/Firefox 最新版 | 功能和样式正常 |
| 分辨率 | 1920x1080/1366x768 | 响应式布局正常 |
| 移动端 | 手机浏览器 | 核心功能可用 |
