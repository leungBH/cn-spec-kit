# 需求文档模板库

> 本文件汇总 cn-spec-kit 中所有可用于 **Step 4 需求文档生成** 的需求文档模板。
> 每个模板在 `templates/` 目录下都有完整的 Markdown 模板源文件，Step 4 在执行时会先读取本索引向用户展示可用模板列表，再按用户选择读取对应模板源文件生成产物。

---

## 模板字段说明

| 字段 | 含义 |
|------|------|
| `id` | 模板唯一标识，对应文件名（不含 `.md` 后缀），也是 `presets/<industry>/<id>.md` 的覆盖文件名 |
| `name` | 模板中文名，向用户展示时使用 |
| `description` | 一句话说明模板适用场景 |
| `chapters` | 模板主要章节（用于向用户预览模板结构） |
| `suitable_for` | 适合的需求类型（功能/大屏/工单流程/事件场景/售前综合/数据开发 等） |
| `industry` | 适用行业，通用（"*"）表示不限行业 |
| `output` | 生成产物的文件名（相对于 `specs/<序号-功能名>/`） |

---

## 模板列表

### 2. requirement-sdd

| 字段 | 内容 |
|------|------|
| 模板名 | AI SDD 标准化需求文档 |
| 适用场景 | 面向 AI SDD（AI 辅助开发）环境的标准需求文档，强调字段级可追溯、可校验、可自动生成代码；按数据开发/流程开发/功能开发分类填充 |
| 适用类型 | 数据开发、流程开发、功能开发 |
| 适用行业 | *（通用） |
| 章节预览 | 需求背景（基础信息/背景价值/约束边界/验收标准/变更追溯）→ 数据开发需求（按需）→ 流程开发需求（按需）→ 功能开发需求（按需） |
| 源文件 | `templates/requirement-sdd.md` |
| 产物文件 | `specs/<序号-功能名>/03-requirement.md` |
| 模板覆盖 | 放入 `presets/<industry>/requirement-sdd.md` 即可覆盖默认模板 |

## 模板查找优先级

Step 4 在加载模板时按以下顺序查找（高优先级覆盖低优先级）：

```
1. presets/<industry>/<id>.md     行业预设
2. templates/<id>.md              全局默认
```

如果用户已选择行业（在 Step 2 需求发现中识别），则先查 `presets/<industry>/`；否则直接走 `templates/`。

## 扩展新模板

要新增一个需求文档模板，需要：

1. 在 `templates/` 下新增 `<id>.md` 源文件
2. 在本 `index.md` 的"模板列表"中追加一段模板说明
3. （可选）在 `presets/<industry>/` 下放置 `<id>.md` 作为该行业预设版本

## 默认模板选择规则

如果用户没有显式选择模板，Step 4 按以下规则自动推荐：

| 条件 | 推荐模板 |
|------|----------|
| Step 1 输入中包含"SDD""AI开发""数据开发""AI辅助"等关键词 | `requirement-sdd` |
| 其他 | 询问用户选择 |
