> 关联文档：[[tob-patterns]]（角色 Archetype）、[[industry-templates]]（行业角色映射）

## 0. 权限等级缩写定义

本文档和权限矩阵模板中使用的缩写：

| 缩写 | 含义 | 说明 |
|------|------|------|
| V | 查看（View） | 可查看数据但不能修改 |
| E | 编辑（Edit） | 可查看+修改数据 |
| D | 删除（Delete） | 可查看+修改+删除数据 |
| A | 全部（All） | 完全控制权限 |
| - | 不可见 | 无任何访问权限 |

## 1. 权限体系概述

中国 ToB 系统的权限体系通常包含 4 个维度，不能只做 RBAC：

| 维度 | 说明 | 举例 |
|------|------|------|
| 菜单权限 | 哪些角色能看到哪些菜单 | 供应商看不到"系统管理"菜单 |
| 操作权限 | 哪些角色能执行哪些操作 | 普通员工不能"删除合同" |
| 数据权限 | 哪些角色能看到哪些范围的数据 | 分公司A看不到分公司B的合同 |
| 字段权限 | 哪些角色能看到哪些字段 | 普通员工看不到"利润率"字段 |

## 2. 常见权限模式

### 2.1 集团型组织权限模式

适用于集团 → 分公司 → 部门 → 岗位 → 员工 5层组织。

| 角色 | 菜单权限 | 操作权限 | 数据权限 | 字段权限 |
|------|----------|----------|----------|----------|
| 集团管理员 | 全部菜单 | 全部操作 | 全公司 | 全部字段 |
| 分公司管理员 | 本分公司相关菜单 | 本分公司相关操作 | 本分公司及下属 | 大部分字段（不含集团级敏感字段） |
| 部门主管 | 本部门相关菜单 | 本部门相关操作 | 本部门 | 业务字段（不含财务敏感字段） |
| 普通员工 | 个人相关菜单 | 个人操作 | 本人创建 | 基础字段 |
| 外部用户 | 授权菜单 | 授权操作 | 授权范围 | 授权字段 |

**跨组织查看规则**：
- 集团管理员：可穿透查看所有分公司数据
- 分公司管理员：可查看本分公司所有部门数据
- 部门主管：默认只看本部门，经授权可看协作部门
- 普通员工：只看本人数据，例外场景需单独授权

### 2.2 多公司型组织权限模式

适用于公司 → 部门 → 岗位 → 员工 4层组织。

| 角色 | 菜单权限 | 操作权限 | 数据权限 | 字段权限 |
|------|----------|----------|----------|----------|
| 公司管理员 | 全部菜单 | 全部操作 | 全公司 | 全部字段 |
| 部门主管 | 业务菜单 | 部门操作 | 本部门 | 业务字段 |
| 普通员工 | 个人菜单 | 个人操作 | 本人 | 基础字段 |

### 2.3 单体型组织权限模式

适用于部门 → 岗位 → 员工 3层组织。

| 角色 | 菜单权限 | 操作权限 | 数据权限 | 字段权限 |
|------|----------|----------|----------|----------|
| 系统管理员 | 全部 | 全部 | 全部 | 全部 |
| 业务主管 | 业务菜单 | 业务操作 | 本部门+跨部门授权 | 业务字段 |
| 普通员工 | 个人菜单 | 个人操作 | 本人 | 基础字段 |

## 3. 审批权限模式

审批权限是 ToB 系统中独特且高频的需求，不能简单归入操作权限。

### 3.1 按角色审批

| 审批场景 | 审批人 | 说明 |
|----------|--------|------|
| 常规审批 | 提交人直属上级 | 最常见模式 |
| 财务审批 | 财务部门指定角色 | 涉金额的审批 |
| 管理层审批 | 总经理/副总经理 | 大额或重要事项 |

### 3.2 按条件分支审批

| 条件 | 审批路径 | 说明 |
|------|----------|------|
| 金额 < 5万 | 部门主管 → 完成 | 低金额简化审批 |
| 金额 5-50万 | 部门主管 → 财务 → 完成 | 中金额标准审批 |
| 金额 > 50万 | 部门主管 → 财务 → 总经理 → 完成 | 高金额严格审批 |

### 3.3 按组织层级审批

| 组织层级 | 审批路径 | 说明 |
|----------|----------|------|
| 部门级 | 部门主管 → 完成 | 部门内事项 |
| 分公司级 | 部门主管 → 分公司经理 → 完成 | 跨部门事项 |
| 集团级 | 分公司经理 → 集团VP → 完成 | 跨分公司事项 |

## 4. 数据权限实现模式

### 4.1 组织范围过滤

| 模式 | SQL示例 | 说明 |
|------|---------|------|
| 本人 | WHERE owner_id = current_user | 只看本人创建 |
| 本部门 | WHERE dept_id = current_dept | 本部门全部数据 |
| 本分公司 | WHERE company_id = current_company | 本分公司全部数据 |
| 全公司 | 无过滤 | 管理员级别 |

### 4.2 字段级权限

| 实现方式 | 说明 | 适用场景 |
|----------|------|----------|
| 前端隐藏 | 低权限角色看不到某些列/字段 | 基础场景 |
| 后端过滤 | API返回时根据角色裁剪字段 | 安全场景 |
| 加密存储 | 敏感字段加密，解密需权限 | 高安全场景 |

### 4.3 特殊数据权限规则

| 规则 | 说明 | 实现方式 |
|------|------|----------|
| 穿透查看 | 上级可看下级数据但不改 | 菜单入口区分"穿透查看" |
| 协作授权 | 跨部门临时授权 | 授权表记录 |
| 数据共享 | 向外部用户共享特定数据 | 共享链接+有效期 |
| 审批查看 | 审批人只能看待审批数据 | 审批队列过滤 |

## 5. 常见权限矩阵模板

### 5.1 CRM 权限矩阵

| 功能 | 集团管理员 | 分公司管理员 | 部门主管 | 销售员 | 外部客户 |
|------|-----------|-------------|---------|--------|---------|
| 客户列表 | V/E/D | V/E | V(本部门) | V(本人) | - |
| 客户创建 | ✓ | ✓ | ✓ | ✓ | - |
| 客户编辑 | ✓ | ✓ | ✓(本部门) | ✓(本人) | - |
| 客户删除 | ✓ | ✓ | - | - | - |
| 客户导出 | ✓ | ✓(本分公司) | ✓(本部门) | ✓(本人) | - |
| 跟进记录 | V/E | V/E(本分公司) | V/E(本部门) | V/E(本人) | - |
| 报表查看 | ✓ | ✓(本分公司) | ✓(本部门) | - | - |
| 客户共享给外部 | ✓ | ✓ | - | - | V(受限) |

### 5.2 OA 审批权限矩阵

| 功能 | 系统管理员 | 部门主管 | 普通员工 | 审批人 |
|------|-----------|---------|---------|--------|
| 发起审批 | ✓(配置测试) | ✓ | ✓ | ✓ |
| 待审批列表 | - | ✓(本部门待审) | - | ✓(本人待审) |
| 审批操作 | - | ✓(一级审批) | - | ✓(对应层级) |
| 审批退回 | - | ✓ | - | ✓ |
| 审批配置 | ✓ | - | - | - |
| 审批统计 | ✓ | ✓(本部门) | - | - |
