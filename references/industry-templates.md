## 1. CRM（客户关系管理）

### 核心模块

| 模块 | 二级功能 | 三级操作 |
|------|----------|----------|
| 线索管理 | 线索录入、线索跟进、线索转化、线索分配 | 创建、编辑、跟进记录、转为客户、分配 |
| 客户管理 | 客户信息、客户分类、客户跟进 | 创建、编辑、分类管理、跟进记录、共享 |
| 商机管理 | 商机创建、商机阶段、商机预测 | 创建、推进阶段、预测金额、关闭 |
| 合同管理 | 合同创建、合同审批、合同执行 | 创建、提交审批、审批操作、变更、续签 |
| 回款管理 | 回款登记、回款计划、回款确认 | 登记、确认、催收提醒 |
| 报表中心 | 销售漏斗、客户分析、业绩报表 | 查看、导出 |

### 角色

| 角色 | 职责 |
|------|------|
| 销售员 | 日常跟进客户、创建商机、提交合同 |
| 销售主管 | 审批合同、查看团队业绩、分配线索 |
| 销售总监 | 审批大额合同、查看全公司业绩、策略调整 |
| 财务 | 审批合同金额、确认回款 |
| 外部客户 | 查看合同和回款进度（受限） |

### 审批流

```
合同：销售员创建 → 销售主管审批(金额<5万) → 财务审批(金额>5万) → 销售总监(金额>50万) → 归档
```

### 关键页面

- 线索列表页、线索详情页
- 客户列表页、客户详情页（含跟进时间线）
- 商机列表页、商机详情页（含阶段推进图）
- 合同列表页、合同创建页、合同审批页
- 回款列表页、回款登记页
- 报表页（销售漏斗、业绩排名）

## 2. ERP（企业资源计划）

### 核心模块

| 模块 | 二级功能 | 三级操作 |
|------|----------|----------|
| 采购管理 | 采购申请、采购订单、供应商管理 | 申请、审批、下单、收货确认 |
| 销售管理 | 销售订单、发货管理 | 创建订单、审批、发货、确认 |
| 库存管理 | 入库、出库、库存盘点、库存预警 | 入库登记、出库审批、盘点、预警设置 |
| 财务管理 | 应收应付、费用报销 | 登记、审批、核销、报表 |

### 角色

| 角色 | 职责 |
|------|------|
| 采购员 | 创建采购申请、跟进采购订单 |
| 采购主管 | 审批采购申请、管理供应商 |
| 仓库管理员 | 入库出库操作、库存盘点 |
| 销售员 | 创建销售订单 |
| 财务 | 应收应付核销、费用审批 |

### 审批流

```
采购申请：采购员创建 → 采购主管审批 → 财务审批(金额>5万) → 总经理审批(金额>50万) → 下单
销售订单：销售员创建 → 销售主管审批(金额>10万) → 财务核价 → 确认发货
库存调拨：仓库管理员申请 → 仓库主管审批 → 执行调拨
费用报销：员工提交 → 部门主管审批 → 财务审批 → 出纳付款
```

### 关键页面

- 采购申请列表页、采购订单详情页、供应商管理页
- 销售订单列表页、发货确认页
- 库存查询页、入库登记页、出库审批页、盘点任务页
- 应收应付列表页、费用报销页、核销确认页

## 3. OA 审批系统

### 核心模块

| 模块 | 二级功能 | 三级操作 |
|------|----------|----------|
| 流程引擎 | 流程定义、流程配置、流程监控 | 创建流程、配置节点、设置条件分支 |
| 待办中心 | 待审批、已审批、我发起的 | 查看、审批操作、退回、转审 |
| 报销审批 | 报销申请、报销审批 | 创建、提交、审批、退回 |
| 请假审批 | 请假申请、请假审批 | 创建、提交、审批、退回 |
| 出差审批 | 出差申请、出差审批 | 创建、提交、审批、退回 |
| 公告管理 | 公告发布、公告查看 | 创建、发布、查看 |

### 角色

| 角色 | 职责 |
|------|------|
| 普通员工 | 发起各类申请 |
| 部门主管 | 审批本部门申请 |
| HR | 审批人事相关（请假、入职） |
| 财务 | 审批报销和费用 |
| 系统管理员 | 配置流程、管理权限 |

### 审批流（通用模式）

```
申请 → 直属上级审批 → 职能部门审批(如需要) → 完成
退回：任何审批节点可退回到发起人或上一节点
```

## 5. 设备管理系统

### 核心模块

| 模块 | 二级功能 | 三级操作 |
|------|----------|----------|
| 设备台账 | 设备登记、设备分类、设备档案 | 登记、分类管理、查看档案 |
| 维保管理 | 维保计划、维保任务、维保记录 | 创建计划、分配任务、执行记录 |
| 故障管理 | 故障报修、故障处理、故障分析 | 报修、派单、处理、关闭 |
| 备件管理 | 备件库存、备件领用、备件采购 | 查询、领用、采购申请 |

### 角色

| 角色 | 职责 |
|------|------|
| 设备工程师 | 故障报修、执行维保任务、记录维保结果 |
| 设备主管 | 审批维保计划、派单、查看设备报表 |
| 仓库管理员 | 备件出入库、备件库存管理 |
| 采购员 | 备件采购申请、跟进采购 |
| 生产操作员 | 上报设备故障、查看设备状态 |

### 审批流

```text
维保计划：设备工程师创建 → 设备主管审批 → 分配任务
故障报修：生产操作员上报 → 设备工程师处理 → 设备主管确认关闭
备件采购：仓库管理员申请 → 设备主管审批 → 采购员执行
```

### 关键页面

- 设备台账列表页、设备详情页（含维保记录时间线）
- 维保计划列表页、维保任务执行页、维保记录页
- 故障报修页、故障处理页、故障分析报表页
- 备件库存查询页、备件领用页、备件采购申请页

## 6. MES（制造执行系统）

### 核心模块

| 模块 | 二级功能 | 三级操作 |
|------|----------|----------|
| 生产计划 | 计划下达、计划排程 | 创建、排程、下达 |
| 生产执行 | 工单管理、报工 | 创建工单、报工登记、完工确认 |
| 质检管理 | 质检任务、质检记录 | 创建任务、质检登记、结果判定 |
| 设备集成 | 设备数据采集、状态监控 | 数据采集、报警处理 |

### 角色

| 角色 | 职责 |
|------|------|
| 车间主任 | 审批排产计划、查看车间数据、质检判定 |
| 班组长 | 报工登记、故障上报、查看本班组数据 |
| 质检员 | 执行质检任务、判定质检结果、记录不良品 |
| 设备工程师 | 设备数据采集配置、故障处理、维保执行 |
| 生产调度员 | 计划排程、工单下达、产能协调 |

### 审批流

```text
排产计划：生产调度员创建 → 车间主任审批 → 工单下达
质检判定：质检员判定 → 车间主任确认(不良品>阈值) → 质量主管复核
完工确认：班组长报工 → 车间主任确认完工
```

### 关键页面

- 排产计划列表页、排程甘特图页
- 工单列表页、报工登记页、完工确认页
- 质检任务列表页、质检登记页、不良品处理页
- 设备状态监控页、报警处理页、OEE报表页

## 7. 合同管理系统

### 核心模块

| 模块 | 二级功能 | 三级操作 |
|------|----------|----------|
| 合同创建 | 合同起草、合同模板 | 创建、选择模板、填写、保存草稿 |
| 合同审批 | 审批流程、审批操作 | 提交、审批通过、退回、撤回 |
| 合同执行 | 合同变更、合同续签、合同终止 | 变更申请、续签、终止 |
| 合同归档 | 合同归档、合同检索 | 归档、检索、查看 |
| 付款管理 | 付款计划、付款登记、付款确认 | 创建计划、登记付款、确认 |
| 合同报表 | 合同统计、合同预警 | 查看、导出、到期预警 |

### 角色

| 角色 | 职责 |
|------|------|
| 业务员 | 创建合同、提交审批、跟进执行 |
| 部门主管 | 一级审批合同 |
| 财务 | 审批金额、确认付款 |
| 法务 | 审批合同条款 |
| 总经理 | 大额合同审批 |
| 系统管理员 | 配置流程、管理权限、管理模板 |

### 审批流

```text
合同审批：业务员提交 → 部门主管审批 → 法务审批(条款审查) → 财务审批(金额确认) → 总经理审批(金额>100万) → 归档
合同变更：业务员申请 → 部门主管审批 → 法务审查 → 归档
合同终止：业务员申请 → 部门主管审批 → 法务确认 → 财务结算 → 归档
退回：任何审批节点可退回到发起人或上一节点
```

### 关键页面

- 合同列表页（含筛选、批量操作）
- 合同创建页（含模板选择、分步表单）
- 合同审批页（含审批意见、审批历史）
- 合同详情页（含执行进度、付款时间线）
- 合同变更页、合同续签页
- 付款计划页、付款登记页
- 合同统计报表页、到期预警页
