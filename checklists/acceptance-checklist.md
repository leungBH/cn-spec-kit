# 验收完整性检查清单

> 生成验收标准后对照此清单自检，缺什么补什么。

---

## 1. 功能验收覆盖度

- [ ] 每个核心功能是否有正常流程验收标准？
- [ ] 每个核心功能是否有异常场景验收标准？
- [ ] 每个核心功能是否有边界条件验收标准？
- [ ] 正常流程验收是否覆盖完整操作链？（从进入页面到完成操作）
- [ ] 异常场景是否覆盖网络异常、并发冲突、数据异常？
- [ ] 边界条件是否覆盖空数据、大数据量、特殊字符？

## 2. 权限验收覆盖度

- [ ] 每个关键操作是否测试了不同角色的可见性？
- [ ] 是否测试了跨组织查看限制？
- [ ] 是否测试了字段级权限？（敏感字段不可见）
- [ ] 是否测试了审批权限？（非审批人不能审批）
- [ ] 是否测试了导入导出权限？

## 3. 数据口径验收

- [ ] 金额计算口径是否与PRD定义一致？
- [ ] 归属规则是否与PRD定义一致？
- [ ] 统计口径是否与PRD定义一致？（已作废排除等）
- [ ] 必填校验是否覆盖所有必填字段？
- [ ] 关联校验是否覆盖？（删除被引用的数据）

## 4. 非功能验收

- [ ] 性能验收是否有量化指标和测试条件？
- [ ] 安全验收是否覆盖登录、数据隔离、XSS、审计？
- [ ] 兼容性验收是否覆盖浏览器、分辨率、移动端？
- [ ] 是否考虑了部署验收？（部署流程验证）

## 5. 验收标准可操作性

- [ ] 每个验收项是否可执行？（有明确的操作步骤和预期结果）
- [ ] 验收结果是否可判断？（预期结果具体，不是模糊描述）
- [ ] 验收项是否与研发任务关联？（验收标准编号对应研发任务编号）
