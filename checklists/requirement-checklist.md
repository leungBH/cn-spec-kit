# 需求文档质量检查清单 (requirement-checklist)

> 用于 Step 4.5 需求文档生成的质量门禁。
> 覆盖率 = 覆盖项数 / 总项数。

---

## 1. 文件存在性

| # | 检查项 | 必需 | 验证方式 |
|---|--------|------|----------|
| 1.1 | `specs/<序号-功能名>/03-requirement.md` 文件已存在 | 是 | 文件系统检查 |
| 1.2 | 文件大小 > 1KB（防止空文件） | 是 | 字节数检查 |
| 1.3 | 文件首行包含 frontmatter 模板标识 | 是 | 文本检查 |

---

## 2. 基础信息表（无论哪种模板都必备）

| # | 检查项 | 必需 |
|---|--------|------|
| 2.1 | 需求ID 填写（格式：类型-日期-序号） | 是 |
| 2.2 | 需求名称 填写 | 是 |
| 2.3 | 需求提出人 填写（姓名+部门+联系方式） | 是 |
| 2.4 | 开发类型 填写（数据/流程/功能） | 是 |
| 2.5 | 优先级 填写（P0/P1/P2/P3） | 是 |
| 2.6 | 版本号 填写（V1.0 起步） | 是 |
| 2.7 | 预计上线时间 填写 | 是 |
| 2.8 | 关联AI SDD配置 填写 | 是 |

---

## 3. 业务背景与目标

| # | 检查项 | 必需 |
|---|--------|------|
| 3.1 | 业务背景章节存在，描述了痛点和必要性 | 是 |
| 3.2 | 需求目标章节存在，包含 SMART 目标（可衡量） | 是 |
| 3.3 | 干系人列表存在（客户方 + 我方） | 是 |
| 3.4 | 需求来源明确 | 是 |
| 3.5 | 应用场景章节存在（含应用部门/岗位/频次/效果） | 是 |

---

## 4. 约束与边界

| # | 检查项 | 必需 |
|---|--------|------|
| 4.1 | 技术约束说明 | 是 |
| 4.2 | 业务约束说明 | 是 |
| 4.3 | 边界说明（包含/不包含内容明确） | 是 |

---

## 5. 验收标准

| # | 检查项 | 必需 |
|---|--------|------|
| 5.1 | 验收标准章节存在 | 是 |
| 5.2 | 至少 3 项量化指标 | 是 |
| 5.3 | 每项指标含验证方式 | 是 |

---

## 6. 模板合规性

| # | 检查项 | 必需 |
|---|--------|------|
| 6.1 | 所选模板的核心章节全部存在 | 是 |
| 6.2 | 表格表头完整 | 是 |
| 6.3 | 示例段落已替换为本次实际内容（非原文复制） | 是 |
| 6.4 | "填写要求"段落已保留在文档中 | 是 |
| 6.5 | `{{占位符}}` 已全部替换或显式标注"待补充" | 是 |
| 6.6 | 章节裁剪合规（按需求类型保留正确模块） | 是 |

---

| 7.1.3 | 环境需求（硬件/软件）章节存在 | 是 |
| 7.1.4 | 功能业务需求章节（按裁剪规则保留） | 按需 |
| 7.1.5 | 大屏类需求章节（按裁剪规则保留） | 按需 |

| 7.1.7 | 事件场景类需求章节（按裁剪规则保留） | 按需 |
| 7.1.8 | 接口需求章节（外部/内部） | 是 |

## 8. 变更追溯

| # | 检查项 | 必需 |
|---|--------|------|
| 8.1 | 变更与追溯记录表存在 | 是 |

## 9. AI 可解析性

| # | 检查项 | 必需 |
|---|--------|------|
| 9.1 | 文档使用标准 Markdown 语法 | 是 |
| 9.2 | 表格用 `|` 语法（非 HTML） | 是 |
| 9.3 | Mermaid 流程图用 ```mermaid 代码块 | 是 |
| 9.4 | 无歧义表述（避免"可能""大概""尽量"等模糊词） | 是 |
| 9.5 | 字段命名与 brief/discovery 中保持一致 | 是 |

---

## 检查结果处理

| 覆盖率 | 处理方式 |
|--------|----------|
| ≥ 90% | ✅ 通过，进入下一步 |
| 70%-89% | ⚠️ 列出缺失项，请用户确认是否需要补充 |
| < 70% | ❌ 回到 Step 4.5 修补 |

输出示例：

```
## Step 4.5 质量门禁检查

总检查项: 30
覆盖项数: 28
覆盖率: 93.3%
结果: ✅ 通过

详细：
✅ 1.1 文件存在
✅ 1.2 文件大小 OK
...
⚠️ 7.1.6 工单流程类需求章节：本次为纯功能类需求，按裁剪规则已省略
✅ 8.1 变更记录表存在
```
