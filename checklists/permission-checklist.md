# 权限完整性检查清单

> 生成权限矩阵后对照此清单自检，缺什么补什么。

---

## 1. 组织层级覆盖

- [ ] 是否覆盖了客户的所有组织层级？（集团/分公司/部门/岗位）
- [ ] 每个层级是否定义了管理员角色？
- [ ] 外部用户（供应商/客户）是否纳入权限体系？

## 2. 权限维度覆盖

- [ ] 菜单权限是否覆盖所有一级模块？
- [ ] 操作权限是否覆盖所有关键操作？（创建、编辑、删除、审批、导出）
- [ ] 数据权限是否定义了组织范围规则？（本人/本部门/本分公司/全公司）
- [ ] 字段权限是否定义了敏感字段可见性？（金额、利润率、联系方式等）

## 3. 跨组织规则

- [ ] 集团管理员穿透查看规则是否定义？
- [ ] 跨部门协作查看规则是否定义？
- [ ] 外部共享数据规则是否定义？

## 4. 审批权限

- [ ] 审批人确定规则是否明确？（直属上级/角色指定/金额条件）
- [ ] 条件分支审批是否覆盖？（不同金额/不同类型走不同审批路径）
- [ ] 审批退回权限是否定义？（谁能退回到哪一步）
- [ ] 审批撤回权限是否定义？

## 5. 导入导出权限

- [ ] 导入权限是否按角色区分？（谁可以批量导入数据）
- [ ] 导出权限是否按角色区分？（谁可以导出什么范围的数据）
- [ ] 导出数据范围是否与数据权限一致？

## 6. 报表权限

- [ ] 报表查看权限是否按角色区分？
- [ ] 报表数据范围是否与数据权限一致？
- [ ] 是否有只查看报表的独立角色？

## 7. 系统配置权限

- [ ] 流程配置权限是否只有管理员可操作？
- [ ] 数据字典配置权限是否明确？
- [ ] 角色权限配置权限是否只有超级管理员？
