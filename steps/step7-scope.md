# Step 7: 开发范围选择 (scope)

## 执行步骤

1. 读取 `04-prd.md` 的功能清单，统计各优先级的功能数量
2. 以结构化提问方式让用户选择开发范围

## 选择选项

> **请选择本次开发的范围**（影响后续所有产物的详细程度）：

| 选项 | 说明 | 适合场景 |
|------|------|----------|
| P0 核心功能 | 只做最高优先级功能，最小可用版本 | 时间紧张、MVP验证 |
| P0 + P1 标准功能 | 覆盖核心+重要功能，完整业务闭环 | 正常一期交付 |
| P0 + P1 + P2 全量功能 | 包含所有规划功能，最完整版本 | 时间充裕、全面交付 |

## 用户选择后的效果

- 后续所有步骤（业务流程、页面原型、权限矩阵、验收标准、研发任务）**只覆盖选定优先级的功能**
- 未选定的功能在产物中简要提及但不展开详细规格
- 页面原型只生成选定优先级对应的页面 HTML
- 研发任务只拆解选定优先级的功能

## 写入范围选择文件

将用户选择结果写入 `specs/<序号-功能名>/05-scope-selection.md`：

```markdown
# 开发范围选择

**选择**: P0 + P1 标准功能
**包含功能**: （列出选定的功能清单）
**不含功能**: （列出跳过的 P2 功能，简要说明二期规划）
```

## 🚪 质量门禁

用户确认选择即通过。
