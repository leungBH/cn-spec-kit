# PRD 模板 - 教育业定制版

> 适用于：教务管理、在线教学平台、学工系统、考试系统、校园管理等教育业 ToB 产品

---

## 1. 项目概述

### 1.1 背景
- **教育机构现状**：当前教务管理的痛点（手工排课、成绩管理混乱、家校沟通困难等）
- **政策要求**：教育信息化 2.0、双减政策、新课标等政策影响

### 1.2 目标
- 教学效率目标（如：排课效率提升 X%）
- 学生管理目标（如：学生信息完整率 100%）
- 家校互动目标（如：家长活跃度 X%）

### 1.3 范围
- 一期覆盖的校区/学段范围
- 二期扩展计划

---

## 2. 组织与角色

### 2.1 组织层级（教育业典型）
```
教育局/集团 → 学校 → 年级 → 班级
```

### 2.2 操作角色
| 角色 | 职责 | 组织层级 |
|------|------|----------|
| 校长/教务主任 | 教务策略、排课审批、教师管理 | 学校 |
| 年级组长 | 年级排课协调、成绩统计 | 年级 |
| 教师 | 授课、作业布置、成绩录入、考勤 | 班级 |
| 学生 | 选课、查成绩、作业提交 | 班级 |
| 家长 | 查看成绩、家校互动、缴费 | - |
| 行政人员 | 校园管理、缴费、设备 | 学校 |

---

## 3. 功能清单

### 教育业核心模块（按优先级标注）

#### P0 必做模块
- **教务管理**：排课、选课、课表管理、考务
- **成绩管理**：成绩录入、统计、分析、排名
- **学生管理**：学生信息、考勤、学籍

#### P1 重要模块
- **作业与教学**：作业布置/提交、课件管理、在线答疑
- **家校互动**：通知推送、成绩通知、家长会预约
- **缴费管理**：学费、杂费、缴费通知、对账

#### P2 规划模块
- **在线考试**：题库、组卷、在线考试、自动批改
- **德育学工**：学生评价、行为记录、社团管理
- **校园设施**：教室预约、设备管理、访客管理

---

## 4. 业务场景

### 教育业典型场景
1. **排课发布**：教务排课 → 年级审核 → 教师确认 → 课表发布 → 学生选课
2. **成绩录入**：教师录入 → 系统计算 → 年级统计 → 家长通知 → 成绩报告
3. **考勤管理**：教师考勤 → 异常标记 → 家长通知 → 补卡审批
4. **缴费流程**：费用发布 → 家长缴费 → 对账确认 → 逾期提醒
5. **家校通知**：学校发布通知 → 家长接收 → 回执确认 → 统计阅读率

---

## 5. 非功能需求

### 5.1 性能
- 排课计算：200+班级排课 ≤ 10秒
- 成绩录入：批量导入 ≤ 5秒
- 家长端：移动端响应 ≤ 2秒

### 5.2 部署
- **典型要求**：公有云 SaaS + 私有化选项（教育局要求）
- 家长端：小程序/APP（微信生态优先）
- 数据安全：学生隐私保护（《个人信息保护法》）

### 5.3 集成
- 微信小程序/企业微信
- 一卡通系统
- 门禁考勤系统
- 教育局数据报送

## 6. 数据口径约定

### 教育业特殊口径
| 口径项 | 约定 |
|--------|------|
| 成绩计算 | 按权重计算（平时X%+期中Y%+期末Z%） |
| 排名口径 | 按年级排名，不公布具体名次（双减要求） |
| GPA计算 | 按学分加权平均 |
| 考勤统计 | 按月统计，迟到3次=1次旷课 |
| 缴费口径 | 按学期收费，逾期按月计算滞纳金 |
| 学籍管理 | 按教育局标准格式，年报报送 |

## 7. 里程碑与交付

| 阶段 | 时间 | 交付内容 |
|------|------|----------|
| M1 | T+4周 | 教务管理+学生管理（核心闭环） |
| M2 | T+8周 | 成绩管理+家校互动（成绩+通知） |
| M3 | T+12周 | 作业教学+缴费管理（全量功能） |

---

## 8. 范围边界

**一期明确要做**：
- P0：教务管理、成绩管理、学生管理
- P1：作业教学、家校互动、缴费管理

**一期明确不做**：
- P2：在线考试、德育学工、校园设施
- 不含：招生系统、校友管理、宿舍分配

**二期规划**：
- 在线考试（防作弊+自动批改）
- 德育学工（行为积分+评优体系）
- 校园设施（预约+巡检+能耗监控）
