# PRD 模板 - 制造业定制版

> 适用于：MES、ERP（制造模块）、WMS、设备管理、质检管理等制造业 ToB 产品

---

## 1. 项目概述

### 1.1 背景
- **工厂/产线现状**：当前生产管理的痛点（手工排产、信息孤岛、质量追溯难等）
- **行业趋势**：智能制造、工业互联网、数字化转型政策要求

### 1.2 目标
- 生产效率提升目标（如：排产效率提升 30%）
- 质量管控目标（如：不良率降低 X%）
- 成本节约目标（如：物料浪费减少 X%）

### 1.3 范围
- 一期覆盖的产线/车间范围
- 二期扩展计划

## 2. 组织与角色

### 2.1 组织层级（制造业典型）
```
集团 → 工厂/事业部 → 车间 → 产线 → 班组
```

### 2.2 操作角色
| 角色 | 职责 | 组织层级 |
|------|------|----------|
| 集团生产总监 | 全集团生产计划审批、产能统筹 | 集团 |
| 工厂厂长 | 工厂级排产、资源调配 | 工厂 |
| 车间主任 | 车间排产执行、质量把控 | 车间 |
| 班组长 | 产线操作、报工、异常上报 | 班组 |
| 质检员 | 过程检验、终检、不良品处理 | 车间 |
| 仓管员 | 物料出入库、盘点、BOM配料 | 仓库 |
| 设备工程师 | 设备维护、保养计划、故障处理 | 设备部 |

## 3. 功能清单

### 制造业核心模块（按优先级标注）

#### P0 必做模块
- **生产计划管理**：订单排产、产能计算、排程优化
- **生产执行管理**：报工、工序流转、异常上报
- **物料管理（WMS）**：出入库、BOM 配料、盘点
- **质量管理**：过程检验、终检、不良品处理、质量追溯

#### P1 重要模块
- **设备管理**：设备台账、保养计划、故障维修
- **工艺管理**：工艺路线、工序定义、参数标准
- **报表中心**：生产日报、质量报表、设备利用率

#### P2 规划模块
- **能源管理**：能耗监控、节能分析
- **供应链协同**：供应商管理、采购协同
- **数字孪生**：产线仿真、产能预测

## 4. 业务场景

每个场景按：触发条件 → 操作流程 → 输出结果 格式描述。

### 制造业典型场景
1. **订单排产**：销售订单下达 → 产能评估 → 排程建议 → 审批 → 下发车间
2. **报工流转**：班组接收任务 → 按工序报工 → 质检 → 下工序 → 完工入库
3. **质量追溯**：不良品发现 → 溯源（人/机/料/法/环） → 处理方案 → CAPA
4. **物料配料**：排产下发 → BOM 展开 → 配料需求 → 仓库发料 → 产线接收
5. **设备异常**：设备故障上报 → 维修派单 → 维修确认 → 恢复生产

## 5. 非功能需求

### 5.1 性能
- 报工实时性：报工数据延迟 ≤ 5秒
- 排产计算：1000+订单排程计算 ≤ 30秒
- 大屏刷新：车间看板刷新 ≤ 10秒

### 5.2 部署
- **典型要求**：私有化部署（工厂内网），离线可用
- 数据采集：支持 PLC/SCADA/MES 数据对接
- 网络环境：工厂车间 Wi-Fi/有线，可能弱网环境

### 5.3 集成
- ERP（SAP/Oracle/用友/金蝶）
- PLC/SCADA 数据采集
- 条码/RFID 扫码设备
- 电子签名/指纹设备

## 6. 数据口径约定

### 制造业特殊口径
| 口径项 | 约定 |
|--------|------|
| 产能计算 | 按标准工时 × 设备可用时间 × 开机率 |
| 不良率 | 不良数/投料数（按工序分段统计） |
| OEE | 时间开动率 × 性能开动率 × 合格品率 |
| 物料消耗 | 按BOM标准用量 vs 实际用量，差异率统计 |
| 成本核算 | 按标准成本 vs 实际成本，差异分析 |

## 8. 范围边界

**一期明确要做**：
- P0：生产计划、生产执行、WMS物料、质量管理
- P1：设备管理、报表中心

**一期明确不做**：
- P2：能源管理、供应链协同、数字孪生
- 不含：多工厂协同、集团级产能统筹、SRM供应商管理

**二期规划**：
- 能源管理（能耗监控+碳排放统计）
- 供应链协同（采购+物流+库存联动）
- 数字孪生（产线仿真+预测性维护）
- 多工厂协同、集团级产能统筹
