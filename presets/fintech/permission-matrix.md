## 3. 数据权限规则

### 3.1 组织范围（金融业特殊点）

| 角色 | 交易数据范围 | 客户数据范围 | 风控数据范围 |
|------|-------------|-------------|-------------|
| 合规总监 | 全行 | 全行 | 全行 |
| 风控经理 | 全行/本分行 | 全行/本分行 | 全行/本分行 |
| 业务主管 | 本分行 | 本分行客户 | 本分行 |
| 柜员/运营 | 本网点 | 本网点客户 | - |
| 审计人员 | 全行（只读） | 全行（只读） | 全行（只读） |
| 财务主管 | 全行清算 | - | - |
| IT运维 | 系统日志 | - | 规则配置 |

### 3.2 跨组织查看规则

- 总行层可穿透查看所有分行数据
- 分行间数据互相不可见（监管隔离要求）
- 审计人员全行只读穿透（仅查看，不可修改）
- 柜员仅可见本网点数据

## 4. 特殊权限说明

### 4.1 审批权限（金融业分级审批）

| 审批类型 | 金额阈值 | 审批人 |
|----------|---------|--------|
| 交易审批 | < ¥5万 | 业务主管 |
| 交易审批 | ¥5万-50万 | 业务主管 → 风控经理 |
| 交易审批 | > ¥50万 | 业务主管 → 风控经理 → 合规总监 |
| 资金调拨 | > ¥100万 | 财务主管 → 合规总监 |
| KYC高级认证 | VIP客户 | 业务主管 → 合规总监 |

### 4.2 数据脱敏规则
- 身份证号：显示前3后4，中间11位掩码
- 手机号：显示前3后4，中间4位掩码
- 银行卡号：显示后4位，其余掩码
- 审计人员查看时需二次授权确认

### 4.3 操作审计要求
- 所有操作必须记录审计日志
- 审计日志不可删除、不可修改
- 敏感操作（审批、拦截、调拨）需双人复核
- 审计日志保留5年
