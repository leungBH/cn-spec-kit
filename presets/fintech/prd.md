# PRD 模板 - 金融业定制版

> 适用于：支付系统、风控平台、资金清算、合规审计、信贷管理等金融业 ToB 产品

---

## 1. 项目概述

### 1.1 背景
- **合规压力**：当前监管要求（银保监/证监/人行）合规痛点
- **风险管控**：现有风控手段不足导致的损失/隐患
- **业务规模**：交易量、资金规模、客户数量

### 1.2 目标
- 合规达标率目标（如：监管检查零违规）
- 风控效率目标（如：风险识别时效 < 5分钟）
- 运营效率目标（如：清算时效提升 X%）

### 1.3 范围
- 一期覆盖的业务线/渠道范围
- 二期扩展计划

---

## 2. 组织与角色

### 2.1 组织层级（金融业典型）
```
总行/总部 → 分行/区域 → 支行/网点 → 业务团队
```

### 2.2 操作角色
| 角色 | 职责 | 组织层级 |
|------|------|----------|
| 合规总监 | 全行合规策略制定、监管对接 | 总行 |
| 风控经理 | 风控规则配置、模型管理、审批 | 总行/分行 |
| 业务主管 | 业务审批、客户管理、交易审核 | 分行/支行 |
| 柜员/运营 | 交易录入、客户开户、日常操作 | 支行/网点 |
| 审计人员 | 内部审计、合规检查、报告 | 总行 |
| 财务主管 | 资金清算、对账、财务审批 | 总行/分行 |
| IT运维 | 系统配置、密钥管理、日志监控 | 总行 |

## 3. 功能清单

### 金融业核心模块（按优先级标注）

#### P0 必做模块
- **交易管理**：交易录入、审批、查询、异常处理
- **风控管理**：风控规则引擎、实时监控、黑白名单
- **合规审计**：操作审计、合规检查、监管报告

#### P1 重要模块
- **客户管理**：KYC认证、客户评级、风险画像
- **资金清算**：清算对账、资金调拨、头寸管理
- **报表中心**：监管报表、风险报表、运营报表

#### P2 规划模块
- **智能风控**：AI风控模型、异常行为识别
- **监管对接**：自动报送、合规检查自动化
- **开放银行**：API开放平台、第三方接入

## 4. 业务场景

### 金融业典型场景
1. **交易审批**：柜员录入 → 风控实时校验 → 金额阈值分级审批 → 执行 → 记账
2. **风控拦截**：实时风控引擎检测 → 规则命中 → 拦截/告警 → 人工复核 → 处置
3. **合规审计**：定期审计任务 → 证据采集 → 合规检查 → 发现问题 → 整改跟踪
4. **资金清算**：日终清算 → 对账核对 → 差异处理 → 清算确认 → 记账
5. **KYC认证**：客户申请 → 信息采集 → 证件验证 → 风险评级 → 审批开户

## 5. 非功能需求

### 5.1 性能
- 交易处理时效：单笔交易 ≤ 500ms
- 风控实时校验：≤ 100ms
- 清算批处理：百万级交易 ≤ 30分钟

### 5.2 安全（金融业特有重点）
- 数据加密：交易数据全链路加密（国密SM2/SM4）
- 操作审计：所有操作留痕，不可篡改
- 密钥管理：硬件密钥/国密证书
- 网络安全：内外网隔离，DMZ架构

### 5.3 部署
- **典型要求**：私有化部署，金融云/本地机房
- 高可用：双活/灾备，RPO=0，RTO<30分钟
- 监管要求：系统备案、数据本地化

### 5.4 集成
- 核心银行系统
- 支付清算网络（人行/银联/网联）
- 反欺诈平台
- 监管报送系统

## 6. 数据口径约定

### 金融业特殊口径
| 口径项 | 约定 |
|--------|------|
| 金额精度 | 小数点后2位，四舍五入（银行会计标准） |
| 交易时间 | 统一使用UTC+8，精确到毫秒 |
| 清算周期 | T+1（工作日），节假日顺延 |
| 风控阈值 | 按客户评级分级设置（A/B/C/D级） |
| 审计追溯 | 全量操作日志保留5年（监管要求） |
| 对账口径 | 按清算日期对账，差异单笔标记 |

| M1 | T+6周 | 交易管理+风控引擎（核心闭环） |

## 8. 范围边界

**一期明确要做**：
- P0：交易管理、风控管理、合规审计
- P1：KYC认证、资金清算、报表中心

**一期明确不做**：
- P2：智能风控、监管对接、开放银行
- 不含：跨行清算、境外汇款、虚拟账户

**二期规划**：
- 智能风控（AI反欺诈模型）
- 监管对接（银保监报送自动化）
- 开放银行（API网关+第三方对接）
