# cn-spec-kit Demo: 考勤管理系统

> **场景**: 制造业中型企业（约 800 人，多厂区）
> **目标**: 替代纸质签到 + Excel 统计，实现考勤流程线上化
> **交付**: 10 份完整产物（端到端流程）
> **生成方式**: 通过 cn-spec-kit 10 步流程自动生成

---

## 1. 场景背景

**客户原话**：
> "我们公司员工越来越多，目前用的还是纸质签到 + Excel 统计考勤，HR 每个月要花 3 天做考勤报表，还经常出错。希望做一个考勤管理系统..."

**核心痛点**：
- HR 每月浪费 3 人天做考勤报表
- 代打卡无法杜绝
- 补卡/请假/加班流程混乱
- 月度数据滞后，工资核算错误率高

**业务价值**：
- HR 效率：3 人天 → 0.5 人天（提升 83%）
- 工资核算错误率：5% → 0.5%
- 员工打卡合规率：70% → 95%

## 6. 适用场景

✅ **适合用 cn-spec-kit 处理的场景**：
- 制造业多厂区统一管理
- 强审批流程业务（请假/报销/合同）
- 强数据隔离需求（部门权限）
- 报表密集型业务（HR/财务）
- 工资核算对接场景

❌ **不太适合的场景**：
- 单一 CRUD 工具（无需完整流程）
- 纯前端项目（无后端逻辑）
- 时间极紧的 MVP（1-2 天交付）
