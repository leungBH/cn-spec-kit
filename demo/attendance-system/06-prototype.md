## 页面详细规格

### Page P1: 员工打卡页

#### 基本信息

| 属性 | 内容 |
|------|------|
| 页面名称 | 员工打卡 |
| 入口路径 | /attendance/clock-in |
| 页面入口 | APP 首页 / 底部导航"考勤" |
| 页面目标 | 员工完成上下班打卡 |
| 适用角色 | 普通员工、班组长、部门负责人 |

#### 布局描述

```
┌─────────────────────────────┐
│  考勤打卡                    │ ← 顶部标题
├─────────────────────────────┤
│                              │
│   2026-06-18 星期四          │ ← 当前日期
│   08:25:30                   │ ← 当前时间（实时刷新）
│                              │
│   ┌──────────────────┐       │
│   │  📍 总厂区 A 区   │       │ ← 当前定位厂区
│   │  在打卡范围内 ✓   │       │
│   └──────────────────┘       │
│                              │
│   上班卡: ✅ 08:01 (正常)   │ ← 当日打卡状态
│   午休出: ⏳ 待打卡         │
│   午休入: ⏳ 待打卡         │
│   下班卡: ⏳ 待打卡         │
│                              │
│   ┌──────────────────┐       │
│   │   📷 拍照并打卡   │       │ ← 打卡按钮
│   └──────────────────┘       │
│                              │
└─────────────────────────────┘
```

#### 元素清单

| 元素 | 类型 | 说明 |
|------|------|------|
| 顶部标题 | 文字 | "考勤打卡" |
| 当前日期 | 文字 | yyyy-MM-dd 星期X |
| 当前时间 | 文字 | HH:mm:ss（每秒刷新） |
| 厂区定位 | 卡片 | 显示当前厂区名称 + 是否在范围内 |
| 打卡状态列表 | 列表 | 展示当日所有打卡点状态 |
| 拍照打卡按钮 | 主按钮 | 调起相机拍照后打卡 |

#### 交互规则
- 进入页面自动获取 GPS 定位
- 不在打卡范围时按钮置灰 + 提示
- 拍照后自动上传打卡（无需再点确认）
- 打卡成功后显示 toast "打卡成功"
- 打卡失败显示错误原因

#### 字段定义

| 字段 | 类型 | 必填 | 来源 |
|------|------|------|------|
| 员工ID | string | 是 | 当前登录用户 |
| 打卡时间 | datetime | 是 | 自动 |
| 打卡地点 | object | 是 | GPS 定位 |
| 打卡照片 | string | 是 | 拍照上传 |
