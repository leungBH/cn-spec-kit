## 1. 角色定义

| 角色 | 简称 | 数据范围 | 关键能力 |

| 普通员工 | EMP | 仅本人 | 打卡、提交申请、查看本人考勤 |

## 3. 数据隔离规则

### 3.1 部门隔离
- 部门负责人只能看**本部门**员工数据
- 部门负责人的"本部门"由其"员工所属部门"决定
- 员工调部门后，权限立即按新部门计算

### 3.2 厂区隔离
- 厂区仅作为考勤组配置项
- 数据访问仍按部门隔离，不按厂区隔离
- 例：HR 经理可看全公司（包含所有厂区）

### 3.3 时间隔离
- 历史数据：所有人可看（按部门隔离）
- 当月数据：同上
- 未来数据：员工本人可看自己的（请假/加班预申请）

## 4. 审批权限细分

| 审批类型 | 审批人 | 越权规则 |
|----------|--------|----------|
| 直属上级 | 员工直接汇报对象 | 直属上级请假 → 升级到部门负责人 |
| 部门负责人 | 员工所属部门的一级负责人 | 部门负责人请假 → 升级到 HR 经理 |
| HR 经理 | 行政 HR 最高负责人 | - |

**禁止配置**: 审批人 = 申请人（系统拒绝这种审批流配置）

## 5. 角色继承关系

```
ADMIN (系统管理员)
  └─ 继承 → HR_MGR (HR 经理)
  └─ 继承 → MGR (部门负责人)  [可选]
  └─ 继承 → EMP (普通员工)

HR_MGR (HR 经理)
  └─ 继承 → HR_OPS (HR 专员)
  └─ 继承 → MGR (部门负责人)
  └─ 继承 → EMP

MGR (部门负责人)
  └─ 继承 → EMP (普通员工)

FIN (财务)
  └─ 仅继承 → 数据接口权限（不继承其他）

HR_OPS (HR 专员)
  └─ 继承 → EMP
```

## 6. 默认角色分配规则

| 触发场景 | 自动分配 |

| HR 部门员工 | HR_OPS |
