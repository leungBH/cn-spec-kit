## 调研范围

## 竞品 1: 钉钉考勤

### 基本信息
- **厂商**: 阿里巴巴
- **定位**: 通用型移动办公套件中的考勤模块
- **目标客户**: 中小企业为主，也覆盖大型企业
- **价格**: 考勤模块免费（依赖钉钉基础版）
- **市场份额**: 制造业市占率约 30%

### 核心功能

| 功能 | 详细 | 借鉴价值 |
|------|------|----------|
| 多种打卡方式 | GPS/蓝牙/WiFi/人脸/指纹 | ⭐⭐⭐⭐⭐ |
| 班次管理 | 固定班次/排班/弹性工时 | ⭐⭐⭐⭐ |
| 请假审批 | 自定义审批流 | ⭐⭐⭐⭐ |
| 加班管理 | 自动换算 | ⭐⭐⭐ |
| 月度报表 | 自动统计 | ⭐⭐⭐⭐ |
| 工资条对接 | 集成钉钉工资条 | ⭐⭐⭐ |
| 跨厂区 | 不支持（每厂区独立考勤组） | ❌ |

### 我们的差距
- ❌ 不支持按"工种"差异化考勤规则（车间/办公室分开统计）
- ❌ 不支持多厂区统一管理
- ❌ 补卡/加班必须事前申请

### 借鉴要点
- ✅ GPS 围栏配置（半径 50-200 米）
- ✅ 打卡方式多选
- ✅ 审批流可视化配置

## 竞品 2: 北森考勤云

### 基本信息
- **厂商**: 北森云计算
- **定位**: HR SaaS 专业模块
- **目标客户**: 中大型企业（500 人以上）
- **价格**: ¥30-50/人/年
- **市场份额**: 中大型制造业市占率约 15%

### 核心功能

| 功能 | 详细 | 借鉴价值 |
|------|------|----------|
| 复杂排班 | 支持倒班、轮班、调班 | ⭐⭐⭐⭐⭐ |
| 工时管理 | 精细化工时统计 | ⭐⭐⭐⭐⭐ |
| 请假/调休 | 自动年假计算 | ⭐⭐⭐⭐ |
| 多组织 | 支持多分公司/事业部 | ⭐⭐⭐⭐ |
| 跨厂区 | 支持多考勤地点 | ⭐⭐⭐⭐ |
| 工种差异化 | 支持 | ⭐⭐⭐⭐⭐ |
| 数据接口 | 开放 API | ⭐⭐⭐⭐⭐ |

### 我们的差距
- ❌ 缺少弹性排班（但本期不做）
- ❌ 缺少年假自动累计（但本期 HR 手动维护）

### 借鉴要点
- ✅ 多考勤地点 + 工种差异化
- ✅ 开放 API（便于对接工资系统）
- ✅ 工时精细化统计

## 竞品 3: Worktile 考勤

### 基本信息
- **厂商**: Worktile
- **定位**: 项目协作 + 轻量 HR
- **目标客户**: 中小企业（50-500 人）
- **价格**: ¥10-20/人/月
- **市场份额**: 中小企业约 10%

### 核心功能

| 功能 | 详细 | 借鉴价值 |
|------|------|----------|
| 简单打卡 | GPS + 拍照 | ⭐⭐⭐ |
| 审批流 | 简单固定流 | ⭐⭐ |
| 报表 | 基础统计 | ⭐⭐ |
| 工时 | 简单统计 | ⭐⭐ |
| 多组织 | 弱 | ⭐ |

### 我们的差距
- ❌ 不支持多级审批
- ❌ 不支持复杂排班
- ❌ 报表功能弱

### 借鉴要点
- ⚠️ 拍照打卡可作为反代打卡的辅助手段

## 差距分析与建议

| 维度 | 钉钉 | 北森 | Worktile | 我们一期 | 二期考虑 |
|------|------|------|----------|----------|----------|
| GPS 打卡 | ✅ | ✅ | ✅ | ✅ | - |
| 班次管理 | ✅ | ✅ | ❌ | 固定班次 | 排班 |
| 请假审批 | ✅ | ✅ | ⚠️ | ✅ 多级 | - |
| 工种差异化 | ❌ | ✅ | ❌ | ✅ | - |
| 多厂区 | ❌ | ✅ | ❌ | ✅ | - |
| 加班管理 | ✅ | ✅ | ⚠️ | ✅ | - |
| 月度报表 | ✅ | ✅ | ⚠️ | ✅ | - |
| 工资对接 | ✅ | ✅ | ❌ | 数据导出 | API 对接 |
| 反代打卡 | ⚠️ | ⚠️ | 拍照 | 拍照 + GPS | 人脸 |

## 差异化建议

1. **工种差异化考勤**: 车间工人（按工时计）+ 办公室人员（按打卡次数计）
2. **多厂区统一管理**: 1 个集团账号下管理多个厂区考勤组
3. **补卡/加班事后补申请**: 3 天内可补，竞品普遍要求事前
4. **月度报表自动发送**: 部门负责人/HR 经理定时收到邮件

## 落地建议

一期建议功能（按优先级）：
- **P0 必做**: GPS 打卡、固定班次、请假/补卡/加班审批、月度报表
- **P1 推荐**: 工种差异化、多厂区、照片反代打卡
- **P2 二期**: 弹性排班、年假自动累计、工资条对接
